# 두 개의 수로 특정값 만들기

## 문제 설명

`n`개의 양의 정수로 이루어진 배열 `arr`와 정수 `target`이 주어집니다.

배열 `arr`에 있는 서로 다른 두 원소의 합이 `target`이 되는 경우가 있는지 확인하세요.

* 합이 `target`이 되는 두 원소가 존재하면 `true`
* 존재하지 않으면 `false`

를 반환하는 `solution()` 함수를 작성합니다.

## 함수 형태

```cpp
bool solution(vector<int> arr, int target)
```

## 제한 조건

* `n`은 2 이상 10,000 이하의 자연수입니다.
* `arr`의 각 원소는 1 이상 10,000 이하의 자연수입니다.
* `arr`에는 중복되는 원소가 없습니다.
* `target`은 1 이상 20,000 이하의 자연수입니다.
* 하나의 원소를 두 번 사용할 수 없습니다.

## 입출력 예시

| arr               | target | result  |
| ----------------- | -----: | ------- |
| `[1, 2, 3, 4, 8]` |    `6` | `true`  |
| `[2, 3, 5, 9]`    |   `10` | `false` |
